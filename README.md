# ACERVO — Seu arquivo de ideias

Mural pessoal para reunir referências, reportagens, links e pautas encontradas em pesquisas, conversas e buscas programadas.

## Objetivo

Centralizar referências em cards com título, link, resumo, abordagem editorial, tags, projeto, formato e notas, com opção de **adicionar cards manualmente** pelo próprio aplicativo.

## Etapas do projeto

1. **Mural visual** — interface responsiva, cadastro manual, filtros, busca e favoritos.
2. **Dados sincronizados** — armazenamento compartilhado e acesso pessoal.
3. **Organização editorial** — projetos, tags e etapas de produção.
4. **Integração com ChatGPT** — salvar referências a pedido do usuário, após configuração e autorização.
5. **Captura rápida** — cadastrar pelo link e facilitar o uso no celular.
6. **Aplicativo para iPhone** — PWA com experiência mobile-first.
7. **Inteligência editorial** — pesquisa contextual e relações entre referências.

## Arquitetura proposta

- **Interface:** HTML, CSS e JavaScript.
- **Hospedagem:** GitHub Pages.
- **Protótipo inicial:** dados salvos localmente no navegador.
- **Evolução:** banco central com autenticação (por exemplo, Supabase), para sincronizar entre celular e computador.

> Repositório público. Não salve chaves, tokens, senhas ou informações privadas no código-fonte. O protótipo local não sincroniza os dados entre dispositivos.
